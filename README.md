# Radiation Monitoring (Ireland)

This project aims to analyze radiation monitoring data collected from the Environmental Protection Agency (EPA) of Ireland. The data, which includes measurements such as radiation levels and nuclide information, is fetched through an API and stored in a MongoDB collection. The geospatial heatmaps give an idea of the distribution of atmospheric radiation levels all over Ireland.

---

## Overview

This project explores radiation measurements and provides tools for:

- Data exploration and cleaning
- Statistical analysis of radiation levels
- Visualization of temporal and spatial patterns
- Early detection of anomalies or irregular exposure
